Tutorials
=========

The following contains tutorials for GMMD.
This includes an introduction to the ``.mgsim`` input file along with more complex examples.
If you are new, we recommend starting with the basic tutorial.

In any tutorial, to learn more about a specific line of code in the input file and its meaning, consult :ref:`input_file_options`.
